A system of two linear equations has no solution exactly when the lines are parallel — equal slopes but different yyy-intercepts.

Find each slope. From 3x−ky=123x - ky = 123x−ky=12 the slope is 3k\dfrac{3}{k}k3​; from kx−12y=16kx - 12y = 16kx−12y=16 the slope is k12\dfrac{k}{12}12k​.

Equal slopes: 3k=k12\dfrac{3}{k} = \dfrac{k}{12}k3​=12k​, so k2=36k^2 = 36k2=36 and k=±6k = \pm 6k=±6.

Check each is parallel-and-distinct (not the same line). For k=6k = 6k=6, the intercepts are −2-2−2 and −43-\tfrac{4}{3}−34​; for k=−6k = -6k=−6, they are 222 and −43-\tfrac{4}{3}−34​. Both differ, so each value gives no solution.

The greatest possible value is k=6k = 6k=6.
